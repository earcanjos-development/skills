# Engineering

Skills for daily code work.

## Model-invoked

The agent reaches for these when a task fits; you can also type them.

- **[human-commit](./human-commit/SKILL.md)**: Draft every commit as a Before / After / Why summary and message, and wait for approval before `git commit`.
- **[human-pr](./human-pr/SKILL.md)**: Draft every PR (title, Before / After / Why, how verified, risks), no tool footer, and wait for approval before `gh pr create`.
- **[refactor-update-shared-methods](./refactor-update-shared-methods/SKILL.md)**: Keep each shared concept in the one module that owns it: `install`, `check`, `audit` and `update` over a Compound Engineering pack.
